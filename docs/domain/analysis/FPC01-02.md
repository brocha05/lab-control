Date analyzed: 2026-10-14   Analyst: Claude Code (for Jorge Davalos)

one sample, 4 specimen rows).

## Purpose of the document

The lab's electronic log: one row per **specimen**, with the field data of its sample
repeated (merged cells) and the test result at its age. general_flow.png describes it
as the "conjunto de registros" that test results complete.

## Relationships & cardinalities

One sample → 4 specimens → 2 at 3 days, 2 at 7 days. Each specimen appears once
(one test per specimen, Q-16).

## Business rules

The Bitácora is a **view** over records, samples, specimens and tests. Every column
maps to a source field or a derived value. This confirms ADR-004 (no table).

## Validation rules

None printed.

## Numbering / identifiers

"Informe" holds the registro number (MCH-068), not the report number
(MAR-PVLT-F1-CTO-REC-068).
