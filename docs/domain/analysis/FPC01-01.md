# Analysis: FPC01-01 — Registro de campo para la recepción de concreto hidráulico

Date analyzed: 2026-10-14   Analyst: Claude Code (for Jorge Davalos)
Source: `docs/lab-pdfs/001 REGISTRO DE COLADO (DE CAMPO).pdf` (scanned, one filled page,
registro MCH-068, pour 02/09/2026).

## Purpose of the document

Paper form filled in **on site during one pour** (*colado*) by the field technician
(*muestreador*). It records the received concrete (one row per truck/delivery), ambient
conditions, the equipment used, and which specimens were molded. A second person signs
"Visto bueno". It feeds the Bitácora (FPC01-02) and the report (FPC06-04).

Standards printed in the header (template text, not data): muestreo NMX-C-161-ONNCCE-2013,
temperatura NMX-C-435-ONNCCE-2010, revenimiento NMX-C-156-ONNCCE-2010, elaboración
NMX-C-159-ONNCCE-2016. Side boxes: NMX-C-162-ONNCCE-2014 (masa unitaria) and
NMX-C-157-ONNCCE-2012 (contenido de aire, método de presión).

## Relationships & cardinalities

- One record = one obra, one pour date, one or more elements ("Elemento(s)").
- One record lists **N deliveries** (4 here; the page has room for ~10, "Hoja _ de _").
- Specimens are referenced on the row of the delivery they were taken from. Here 1 of 4
  deliveries was sampled, giving 4 specimens.
- Mold keys and specimen keys are listed in the same order (A-62).

## Workflow states / signatures / approvals observed

Two signatures: Muestreador and Visto bueno. No state is printed. Nothing says when the
record is "complete" (Q-33).

## Business rules

- The age reference date is the "Fecha del colado" (confirmed by FPC06-04).
- The "Datos de proyecto" belong to the record. Different elements of the same obra can
  have different f'c, so they aren't project-level (A-75).

## Conflicts with current model

1. The model had no Delivery entity; Sample hung directly from FieldRecord.
2. `recordDate` had undefined semantics. It is the pour date, so it's renamed `pourDate`.
3. Specified properties (f'c, slump, aggregate size, cement type, design age) were
   assumed to be project fields. The form puts them on each record.
